# SlotCars

A small, experimental 3D slot car game built with JavaScript and WebGL.

SlotCars demonstrates how a collection of simple geometric shapes, textures and a movable camera can become an interactive 3D world.

There are no heavyweight graphics frameworks involved — just JavaScript, WebGL and a little imagination.

## What's inside?

- A simple WebGL graphics engine
- 3D geometry and textured buildings
- Cars that race on the track
- Camera movement and keyboard interaction
- A frame-rate monitor

The source code is divided into sections to make it easier to explore and experiment with.

## Getting started

Open `index.html` in a WebGL-capable browser using a local web server.

## Controls

Use the arrow keys to explore the street scene.

- ↑ Up — Faster
- ↓ Down — Slower
- ← Left — Change Lane to the Left
- → Right — Change Lane to the Right
